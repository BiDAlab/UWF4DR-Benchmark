# Requirements

This directory contains Python dependency files for the different model families
used in the experiments.

Each file is intended to be installed in a **separate Python environment**, as
different model families rely on distinct and potentially incompatible software
stacks.

- `cnn.txt`  
  Dependencies for convolutional neural network (CNN) models.

- `vit.txt`  
  Dependencies for vision transformer (ViT) models.

- `retfound.txt`  
  Dependencies for RETFound-based retinal foundation models.

Users should select and install **only the requirements file corresponding to
the model family they intend to evaluate**.
